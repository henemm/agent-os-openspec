# Fast Track: Fußzeilen-Widerspruch (#235), Zweck vor Ticket (#187), Gegenbefunde (#190)

## Problem

- #235: Der Versions-Marker-Baustein (`scripts/sync_skills.py::marker_block`, in alle Skills generiert) verlangte, Phase und Schritt „wörtlich“ aus dem Hinweis von Turn-Beginn zu übernehmen, und verlangte zugleich nach einem eigenen Phasenwechsel den neuen Stand. `/40-tdd-red` nannte im Abschlussblock `phase5_tdd_red` als aktuelle Phase, obwohl der Befehl direkt davor `phase6_implement` setzt.
- #187: `/01-feature` legte Issues an, bevor der Zweck des Features mit dem PO geklärt war.
- #190: Analysen bestätigten tendenziell den Plan; Gegenbefunde und Vergleichszahlen fehlten.

## Scope

- `scripts/sync_skills.py`: eine widerspruchsfreie Regel für die Fußzeile; `skills/*/SKILL.md` und `.claude/commands/*` neu erzeugt
- `core/commands/40-tdd-red.md`: Abschlussblock nennt erledigte und neue Phase
- `core/commands/01-feature.md`, `core/agents/feature-planner.md`: Zweck bestätigen lassen, bevor ein Issue entsteht
- `core/commands/20-analyse.md`: Bewertungsauftrag um Gegenbefunde und Variantentabelle ergänzt
- Nicht enthalten: neue Gates, neue Pflichtsektionen in Spec oder Analyse, Baseline-Regel im Core

## Definition of Done

Die Widersprüche sind durch Tests belegt, die ohne die Änderung rot sind; die volle Suite bleibt grün.

## Acceptance Criteria

- **AC-1:** Given der generierte Marker-Baustein, When er gelesen wird, Then enthält er kein „wörtlich von dort“ mehr und nennt als Quelle den Stand am Ende der Nachricht (`workflow.py status` nach eigenem Wechsel).
- **AC-2:** Given der Abschlussblock von `/40-tdd-red`, When er ausgegeben wird, Then nennt er `phase6_implement` als aktuelle Phase.
- **AC-3:** Given `/01-feature` und `feature-planner`, When ein neues Feature geplant wird, Then wird ein Issue erst nach bestätigtem Zweck angelegt.
- **AC-4:** Given `/20-analyse` Step 3, When die Bewertung beauftragt wird, Then verlangt der Auftrag Gegenbefunde und bei Vergleichen eine Variantentabelle vor der Empfehlung.

## Test Plan

- `tests/test_skills_sync.py` (AC-1, AC-2), Sichtprüfung der Befehlstexte (AC-3, AC-4), volle Suite
