# Fast Track: qa_gate wertet Swift-Testing-Läufe aus (#388)

## Problem

`qa_gate.py` wertet bei xcodebuild-Läufen nur die XCTest-Zeile `Executed N tests, with M failures`.
Swift-Testing-Tests (`@Test`) zählen dort nicht mit. Ein Lauf, der nur eine Swift-Testing-Suite
auswählt, druckt `Executed 0 tests` und wird als „0 tests executed“ abgelehnt, obwohl die Suite grün
ist. Ein voller Lauf meldet nur die XCTest-Zahl.

## Scope

- `core/hooks/qa_gate.py`: neue Funktion `_swift_testing_result()`; `validate_test_output` verrechnet sie mit der Executed-Zeile; `TEST_PATTERNS` erkennt die Swift-Testing-Summary
- Nicht enthalten: Zählung übersprungener Tests über die `➜`-Zeilen hinaus; andere Runner

## Definition of Done

Der Fundfall ist durch einen Test belegt, der ohne die Änderung rot ist; die volle Suite bleibt grün.

## Acceptance Criteria

- **AC-1:** Given eine grüne Swift-Testing-Summary und `Executed 0 tests`, When `validate_test_output` läuft, Then ist das Ergebnis PASSED mit der Swift-Testing-Zahl.
- **AC-2:** Given XCTest- und Swift-Testing-Tests in einem Lauf, When ausgewertet wird, Then nennt die Meldung die Summe beider.
- **AC-3:** Given eine `✘`/`✖`-Zeile, eine fehlgeschlagene Suite oder eine rote Summary, When ausgewertet wird, Then ist der Lauf rot — auch in xcbeautify-Ausgabe ohne Summary.
- **AC-4:** Given ein Swift-Testing-Lauf ohne Executed-Zeile, When ausgewertet wird, Then wird er nach der Swift-Testing-Summary gewertet.
- **AC-5:** Given XCTest-Fehler, null Tests oder nur übersprungene Tests, When ausgewertet wird, Then bleibt das Ergebnis rot bzw. NOT PASSED.
- **AC-6:** Given mocha-/node-Ausgabe mit `✔`-Zeilen ohne Swift-Testing-Summary oder Suite-Zeile, When ausgewertet wird, Then greift der Swift-Testing-Zweig nicht.
- **AC-7:** Given eine grüne Swift-Testing-Ausgabe und danach `** TEST FAILED **`, `** BUILD FAILED **`, `Testing failed:` oder `Restarting after unexpected exit`, When ausgewertet wird, Then ist der Lauf rot.
- **AC-8:** Given die SF-Symbol-Ausgabe auf macOS (􁁛/􀢄), Suite-Namen ohne Anführungszeichen oder Fehlerzeilen mit zwei Leerzeichen, Tab oder Variationsselektor, When ausgewertet wird, Then gelten AC-1 und AC-3 ebenso; `passed … with N known issue(s)` ist kein Fehlschlag.
